# Git & GitHub Beginner Lab

## Project Description

This project is created for practicing basic Git and GitHub commands.

## Project Files

- `main.py` - Main Python program
- `marks.py` - Student marks calculator
- `student_info.txt` - Student information
- `README.md` - Project documentation

## Git Workflow

The main Git workflow used in this lab is:

git status
git add
git commit
git push
git pull

## Learning Objectives

By completing this project, students will learn how to:

- Create a Git repository
- Track files
- Stage changes
- Commit changes
- Push changes to GitHub
- Pull changes from GitHub
